Sameel Enterprises

Pharmaceutical Distribution & Order Management System

A full-stack web application designed to simplify pharmaceutical distribution operations, medicine catalogue management, inventory tracking, pricing and customer order booking.

Key Features

- Role-based authentication for administrators, managers and order bookers.
- Pharmaceutical company management.
- Separate medicine catalogues for each company.
- Medicine catalogue import through Excel.
- Customer management.
- Inventory and stock management.
- Medicine pricing management.
- Customer order booking and approval workflow.
- Order status tracking.
- Responsive React-based interface.

Technology Stack

Frontend

- React.js
- Vite
- JavaScript
- CSS

Backend

- Node.js
- Express.js
- REST API
- JWT Authentication

Database

- MySQL

Project Purpose

The goal of this project is to digitize pharmaceutical distribution operations and provide a centralized platform for managing products, customers, inventory and orders.

Installation

Prerequisites

- Node.js
- npm
- MySQL Server
- Git

Clone Repository

git clone https://github.com/waleed1231/sameel-enterprises-distribution-app.git
cd sameel-enterprises-distribution-app

Backend Setup

cd backend
npm install
npm run dev

Configure your backend ".env" file with the required database credentials and JWT secret before starting.

Frontend Setup

Open another terminal:

cd frontend
npm install
npm run dev

Open:

"http://localhost:5173"
